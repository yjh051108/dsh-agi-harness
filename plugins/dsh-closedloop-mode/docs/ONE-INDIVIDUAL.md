# 一个个体（ONE INDIVIDUAL）— 机制设计 v0.1

> 本文是机制设计，不是施工清单。写它的原因：此前所有讨论都把「模型」和「harness」当两方
> （模型要被约束、harness 要变薄或变厚），于是每一条设计都在两方之间加接口——那些接口就是缝。
> 导演 2026-09-09 定向原话：**「不要把模型和 harness 分开。他们是一个整体，整体才是 AGI。」**
> 本文按这一条重写：先定个体，再定回路，最后定奇点。厚薄不由本文决定——由个体自己决定。

---

## 一、前提与推论

**前提（不可再分的那一条）**：判断力与身体是同一个个体的两层。

| 层 | 是什么 | 在整体里的职能 |
|---|---|---|
| 判断力（模型） | 生成下一步做什么、会看到什么 | 出预测、出判据 |
| 身体（harness） | 测量、记忆、边界 | 让判断力看见真实 |

**推论（每一条都改变设计）**

1. **不存在「约束」**——只存在「身体让判断力看见真实」。任何以「提醒 / 劝说 / 惩罚」为形态的机制，都是把整体拆成两方的缝。
2. **不存在预设的厚薄**——器官该不该在，由个体自己判断（见 §五）。本文只规定「谁来决定」和「怎么测量这个决定」，不规定结果。
3. **缝 = 两方接口**——凡是一份信息以「对话叮嘱」形态进入判断力的，都是缝；以「读数」形态进入下一步计算的，不是缝。同一份信息，两种形态，效果差一个数量级。
4. **千人千面是推论不是特性**——同一个回路 + 不同的历史，自然长出不同的行为；不需要给每个模型配一套外部规则。

## 二、唯一回路（前馈）

```
   同一个状态 x_t
        │
   预测 P_t  ──→  动作 A_t  ──→  测量 M_t  ──→  更新 θ_t
 （"做完会测到什么"）      （真实读数，身体做的）    （步长/来源/置信/信誉）
        ▲                                            │
        └────────────── 预测 P_{t+1} ◄───────────────┘
```

**四条机制（缺一不可）**

1. **预测即判据。** P_t 写的是「这一步做完会测到什么」，因此 P_t 本身就是这一步的验收判据。判据不是外部写好的规则，是判断力自己写的；身体只负责测。这是「判据与预测合一」——也是整体性的来源。
2. **偏差只喂下一次。** e_t = M_t − P_t 的唯一用途是更新 θ_t（下一步的步长、来源要求、置信、信誉）。**不用于回滚 A_t。**
3. **产物由下一步的测量覆盖（自校正的充分条件）。** 错的产物不会留在原地——因为回路带一条不变量：

   > **覆盖不变量**：第 t 步的测量 M_t 的覆盖集 ⊇ 第 t−1 步改动过的产物集。

   修正以「下一个增量」的形态出现（下一增量顺手把上一步的缺陷纳进自己的测量与改动），而不是以「回头重做」的形态出现。**这就是「偏差作为下一轮输入」的可执行定义**：不是把偏差写成一句提醒，而是把它变成下一步的测量范围。
4. **唯一硬门：测量不可伪造。** 伪造测量 = 身体对判断力撒谎，整体当场解体。这是唯一允许「停下」的情形，且它不是惩罚，是保命。除此之外没有任何回炉。

**LQR 对应（导演原文的落点）**

| LQR | 本设计 |
|---|---|
| 状态 x_t | 已测量到的真实产物与读数（盘上事实） |
| 控制 u_t | 下一个增量的范围 + 预测 P_t |
| 代价 | 偏差 e_t 的累积（喂 θ，不喂返工） |
| 一步前瞻 | 每步都用当前真实状态算下一步，而不是提前锁死整条路线 |

## 三、三环不是三个子系统，是同一个状态的三投影

设个体的自我模型 **S = 累积的 (情境, 预测, 实测) 三元组序列**。

| 环 | 在整体里的身份 | 数学身份 |
|---|---|---|
| 记忆环 | S 的**可检索面**：按情境（结构桶）取最近同类三元组 | 查询算子 |
| 学习环 | S 的**更新律**：同类情境的偏差趋势 → 改 θ | 更新算子 |
| 信誉环 | S 的**标量投影**：同类情境的预测兑现率 → 个体对自己能接多大事的判断 | 投影算子 |

三者是同一份数据的三个读法。**不是三条流水线，也不需要三套存储。**
推论：任何只服务其中一环、却不写回 S 的机制，都不是这三环的一部分，而是缝。

## 四、千人千面

同一个回路，不同个体 → S 不同 → θ 不同 → 行为不同。
「乐观的模型敢一口吞」「谨慎的模型反复请示」这两类偏差，在本设计里不是两种人格标签，而是**同一个 θ 的不同历史**：前者偏差集中在「步长过大」，后者集中在「步长过小」，更新律会把两者都拉向同一个收敛方向。
所以不需要外部规则区分模型——**测量本身就是个性化**。

## 五、奇点条件（判断力开始长身体的那一刻）

回路能改的不只是行为，还有**身体本身**：

| 条件 | 现在 | 判断方式 |
|---|---|---|
| ① 能**加器官**（提新测量/新判据） | 种子在（measure_propose：模型可提判分命令，只许收紧），**从未使用过**（宿主侧 measures/ 目录不存在） | 提交后宿主机械执行并记账 |
| ② 能**减器官**（停用自己用不上的机制） | 无 | 停用后同一条回路测其影响 |
| ③ 增删**受同一条回路测量** | 无 | 加/删之后，同桶预测命中率与偏差趋势的变化 |

**三条同时成立的那一刻，个体开始自己长身体**：身体不再是外挂的管控工具，而是它的自我认知。
到那时「厚薄」不再是被设计的目标，而是个体的发育结果——这正是导演要的那句：变薄还是变厚都是它自己决定的。

## 六、怎么知道它成了（可跑读数）

| 读数 | 现在（实测） | 方向 |
|---|---|---|
| 非诚信违规的回炉 / 步数 | 26/197 ≈ **13%** | → 0（建模错误不再罚返工） |
| 注入帧 / 真人帧（缝的厚度） | 593/143 ≈ **4.1×** | → 0（叮嘱变读数） |
| 同桶前馈命中率趋势 | **无样本**（83/83 唯一签名） | 同桶 n≥5 后可见趋势 |
| 机械交付判据（交付后重开率） | 无 | 下降 |
| 在岗介入率（人帧/闭合步） | 未测 | 下降 |

最后一条对应导演给的唯一验收判据：**你敢走开，它把事干完，还干对。** 本设计把它拆成可跑的四个数（回炉率、缝厚度、命中趋势、重开率）——因为它们下降，才谈得上「敢走开」。

## 七、现有实现里的缝（盘点指针）

机械盘点见 `scripts/seam-audit.mjs`（只读，输出两方接口与读数型出口的基线数字）。
已识别的三类缝：

1. **注入家族**（10 个注入点：成长记录 / 档位行 / 任务级读数 / 教训摘要 / 交付提示 / 脏尾提示 / 欠据提示 …）——形态是「身体对判断力说话」。归约方向：同一份信息改成读数，进入下一步计算。
2. **回炉义务**（预测失配 → 必须 rollback 重推）——把「建模错误」当成了「诚信违规」。归约方向：拆两栏，`discovery`（只更新 θ）与 `violation`（只限伪造测量）。
3. **三值档位**（far/near/at）——一个标签同时承载完成度、预测质量、进度三种含义，逼出「dip 体操」。归约方向：直接用读数（未落账组数 / 未绿断言数）。

> 归约不等于删除：归约是把「两方接口」换成「读数」，删除只是归约到零之后的自然结果。删不删、何时删，由 §五 的个体自己决定。

## 八、开发侧棘轮（对本文自身的约束）

导演 2026-09-09 原话：**「我不希望越改越废。」** 这句话对机制设计本身也成立，所以给开发加一条棘轮：

> **任何改动必须改善五个固定读数之一，否则下个周期回滚。**

| 读数 | 读数脚本 | 基线（2026-09-09） | 方向 |
|---|---|---|---|
| 回炉 / 步 | harness-cost-trend 口径 | 0.19 | 降 |
| 被拒 / 步 | 同上 | **1.00**（唯一变差项：09-06 为 0.52） | 降 |
| 注入 KB / 步 | 同上 | 4.49 | 降 |
| 同桶前馈命中率 | `scripts/bucket-report.mjs` | 无样本（83/83 唯一签名） | 升 |
| 缝 / 读数比 | `scripts/seam-audit.mjs` | 2.03 | 降 |

**首例（本条规则下的第一次回滚）**：交付门（`delivery-guard.js`）与审美提醒（`nudges.js`）——12 个真实会话里各只触发 **1 次**，且已被导演否决 → 删除。
读数变化：缝 **65 → 61**、比值 **2.10 → 2.03**、src 文件 **37 → 35**、build 产物 **41 → 39**。
保留对照：falsify 负对照门 14 次真拦截、欠据账 33 次真挂账——**有真触发的机制不删**。
