## 0. 一句话

**人只提出要求、保留打断主权；"模型 + 外置 harness"的耦合系统全自主地沿最优路径收敛到交付——实时可打断、可注入变量、可中途改目标，而收敛性不破。**

## 1. 哲学公理

- **A1 质量是系统的属性，不是模型的属性。** 等更强模型、堆提示词、调权重，全是开环赌注。闭环让交付质量成为结构性质：模型可换，质量曲线不断。"代际提升"的来源是**换架构**，不是换零件。
- **A2 前馈为主，反馈为辅；全局前瞻发生在每一步。** 单步最优=全局最优的真义不是"不前瞻"——是**每步基于当前实测状态（目标、残差、代价、增益先验）全局前瞻，算出最优微分单步；下一步拿新状态重算**。前瞻每步重做，承诺只有一步。选 LQR 的深意：它的最优解**时一致**——每步重算 horizon 前瞻，第一步与"应用增益" u=−Kx 精确同解，全局前瞻坍缩成状态→动作的流场（Riccati=Bellman 不动点）。"看全局、走一步"不是折中，是定理。与 MPC 之别：MPC 每步重搜索且承诺一段；本结构每步重前瞻且锚在测量上，合同+K 先验让前瞻便宜且一致，ΔV 证书兜住不一致的时刻。
- **A3 这是最类人的控制。** 人的综合思考=每刻预演全局（经验+目标+现状），只落最优下一步；下一刻预演随新状态更新。心流感即流场：方向由当前状态给，不由存储的计划给——所以**顺应惯性**（不回炉、不重启，沉没成本为零）；每步预演锚在实测上——所以**快速收敛**（纠正是免费的）。要 AGI 行为，就按这个控制结构建，不是按数据库检索建。
- **A4 最优性住在增益（每步重算的流场）里，不住在计划里。** 这是"实时可打断不影响收敛"的数学根据：LQR 的 K 对任意初始状态同解——扰动、注入变量、改目标，都只是新状态/新参考点，同一个环吸收它。没有任何东西以"计划"的形态存着，所以打断无"计划"可破坏。开环计划遇变更=作废重启；闭环遇变更=新 x，继续收敛。定理7（轨迹不入合同）是本公理的推论。
- **A5 人不是监工，人是参考输入。** 人的主权恰好三样：提要求（定 Q）、打断/注入/改目标（setpoint 通道）、验收（合并按钮）。除此之外人不出现。"没人管"不是缺功能，是设计目标。
- **A6 测量是传感层，不是产品。** 诚实、闸、审计——它们是反馈为辅的那个"辅"：反馈层不可信则环无效，所以无测量不放权、棘轮只收紧、案底=教具。但北极星不卖诚实——诚实是仪表盘的精度，车要去的目的地是**始终最优的开发路径**。

## 2. 三性（用户点名，逐条定义）

| 性 | 含义 | 现居何处 | 缺口 |
|---|---|---|---|
| **连续性** | 状态活在盘上：跨步、跨会话、跨换代不断链；模型可换，环的记忆与势能不断 | 盘档 v3 + V 账本 + engram | 已基本成立 |
| **学习性** | 增益被盘上证据更新：每跑一单，前馈变强、反馈变轻；死的 harness K 恒定，活的 harness K 进化 | **缺**（案底只被人读） | v0.5 主件 |
| **自主优化收敛性** | ΔV 严格降=Lyapunov 证书；棘轮保证证书不可被环内策略削弱；终端归零才叫完 | 三要素闸 + 棘轮 | 已成立，但被弱前馈拖累（见 §5） |

## 3. 融合命题：ReAct 优点 × spec 优点 × 两者都没有的

- **ReAct 的优点**=单步适应、工具落地、无计划刚性 → 我们的快环（每步提议=全局前瞻后的微分步，cost-to-go 最小者胜）。
- **spec 的优点**=验收可查、意图连续、合同先行 → 我们的慢环（Q_N 合同、断言=测量函数）。
- **两者都没有的**=①收敛证书（ΔV 严格降+终端归零，"完成"是测出来的不是宣布的）②增益学习（案底→K 更新律，越跑越强）③棘轮（定义权单向阀）。
- 融合形态一句话：**模型驱动的单步最优执行决策做增量开发**——每步像 ReAct 一样落地，方向由合同增益决定，收口像 spec 一样可测，路径最优由证书保证。

## 4. 终态画面（做成了什么样）

1. 人说一句要求 → 系统自主开单：从增益档案**起草**合同（不从零手推），人可看可不看。
2. 执行：declare→实现→converge 快环自跑，测量闸吃残差，阻尼只在信号触发时出一行；无确认弹窗、无仪式。
3. 人随时打断/加变量/改目标 → 在途步机械结算（归因=外部 setpoint 变更，不污染回炉统计），新状态入环，V 链换段续算，收敛性不断。
4. 收工：terminal 归零 + 独立审落账 + **本单经验自动蒸馏回增益档案** → 下一单的前馈更强。
5. 模型换代：换 provider，盘上连续，质量曲线不破。
6. 人的总介入次数/单 → 趋近零（除三次主权动作外）。

## 5. 现状与北极星的差距（诚实审计）

- 反馈层（收敛性）已立；**前馈层太弱**：合同每单从零手推 → 实测 18 条回炉归因 72.2% 预言失效——"反馈为辅"被过兑成"反馈为主"，违背 A2。修法是增益变强，不是闸变严。
- 学习性为零：案底文化建好了数据面，更新律没建——数据在睡觉。
- setpoint 通道靠人肉 off/弹窗（还弹错了，F1）：A4 的数学保证还没变成接口。
- 路径最优缺 R：u=−R⁻¹B'P 没有动作定价，"始终最优"数学上未定义（现状=cost-to-go 贪心，R→0 极限）。

## 6. 可证伪（北极星怎么被杀死）

- **学习性证伪**：增益档案上线后，预言失效率不随单数下降 → A2 的外置增益路线错，回炉设计。
- **打断实验**：中途改目标，若账本出现孤儿步/V 链断裂需人肉清理 → A4 在工程上不成立。
- **配对实验**：档案起草合同 vs 手写合同，ΔV/cost 与回炉率无显著差 → "越跑越强"是故事。
- **代际实验**：同模型开环对照（Superpowers 式纪律）跑平 → 改名，不称颠覆。
- 案底文化对北极星自身生效：被杀就认，写进文档，改道继续。

## 7. 非目标

- 不等更强模型，不训练新权重（v0.5 纯工程；训练是 v1.0 选项不是前提）。
- 不做多路分叉树搜索/不冻结轨迹（A2 的前瞻是一次全局思考落一步，不是分叉搜索；也不做 MPC 式每步重规划承诺一段）。
- 不卖"诚实"当产品（A6：它是传感精度）。
- 不把人做成审批节点（A5：人是参考输入）。
- 不做死 harness 的修补匠——每一版都必须让"环"本身更强，不是让仪式更多。
