# THEORY-v0.5 — 增益外置：让 harness 活过来（设计蓝图）

> 北极星：docs/NORTHSTAR.md（一切组件服务 §2 三性与 §4 终态）。
> 定位三代：**v0.3 骨架**（合同+闸+账本，闭环成立）→ **v0.4 反馈血肉**（测量 z、基数 V、棘轮、借据、阻尼）→ **v0.5 前馈大脑**（增益外置 K、动作定价 R、setpoint 通道、更新律）。
> 一句话：反馈层已够，**"反馈为辅"的前提是"前馈为主"**——v0.5 把前馈做强，让闸退回吃残差的本职。
> 纪律沿用：搬结构不搬公式；拒绝文本即条款；棘轮只收紧；测试即合同；无测量不放权。

## 0. 诊断依据（为什么是这四件）

- 实测 18 条 re-linearize 归因：**预言失效 72.2%**（先验估算/源读不全/机制外推为大头）、前提变更 16.7%、协议摩擦 5.6%、闸门设计 5.6%（dsh-实测归档/closedloop-04-dogfood-r1/rollback-classification.json）。→ 回炉的主因不是闸摩擦，是**每单从零手推合同**。
- 数学缺口：u=−R⁻¹B'P——现状无 R，"路径始终最优"未定义；现状快环=cost-to-go 贪心=R→0 极限。
- 接口缺口：A4（最优性住在增益里→打断廉价）无工程通道；中断/改目标靠人肉 off+弹窗（且 autoConfirm 被弹窗架空，F1）。
- 数据缺口：案底/合同成败/V 曲线=比 benchmark 分数更富的性能信号（带错层归因），只被人读，未被环读——学习性=0。

## G1 增益档案（K-table）——学习性的载体

**结构**（宿主侧 `graded-state/k-table/`，sha 历史链，同 measure-spec 惯例）：
```
entry = {
  sig,            // 情境签名：任务型 × 组粒度 × 断言形状（S1 用结构化标签，embedding 后置——开放问题 Q1）
  template,       // 合同草案形状：purpose 句式 / 断言模板 / measure kind 偏好 / 组切分先验
  sourceModel,    // 源质量模型：{measured|read|estimate 类 → 历史命中率}（G4 更新）
  prior,          // 预期 ΔV/cost 分布（来自同类历史单）
  evidence,       // 来源单链：[{sid, terminalAt, vCurve, rollbackAttr}]——可展开可复核
  hits, misses    // 本 entry 被采纳后预言失效计数（增益本身被测量=meta 闭环）
}
```
**写通道**：terminal_check 时机械蒸馏（G4），产出候选 entry——方向受棘轮约束：**新 entry/收紧先验=auto；放宽/退役=人审**（判分器单向阀升维到增益层）。
**读通道**：cost_set/decompose 自动召回最近邻 ≤3 entry → **合同草案**（前馈）；模型从"写合同"降级为"改草案"。手推=冷启动路径保留（无档案命中时显式标注 cold-start，计入 sysid 史）。**注**：K-table 是前瞻的先验不是前瞻的替代——按 NORTHSTAR A2，快环每步仍做全局前瞻算微分单步；档案的作用是让这次前瞻便宜且时一致（同类情境给出同方向的第一步）。
**验收**：配对实验（§F3）——草案合同 vs 手写合同，预言失效率与 ΔV/cost 对比。

## G2 动作定价（R）——路径最优的数学补全

- 粗类表（合同级、棘轮管控）：`read=1 / edit=2 / subagent=3 / workflow=4 / build=5 / test=5 / restart=10`（初值=经验默认，Q2 待拍板）。
- 快环提议判据：argmin cost-to-go → **argmin ΔV̂/Ĉ**（Ĉ=动作类的定价；ΔV̂=prior 投影）。stateFace 提议行随之改口径：「▸ 提议：ΔV/Ĉ 最大者」。
- 记账：`closed[].cost`（条件展开防键漂移）+ 单级 Σcost；v04-metrics 四数升五数：**ΔV/cost**。
- 闸不动：三要素原样——R 只改"选哪个动作"的投影，不改"闭没闭合"的判定。

## G3 setpoint 通道——"实时可打断不影响收敛"的接口化

三事件一通道（用户消息到达即触发，纯状态机，零 LLM）：
1. **打断/注入变量**：在途 open 步机械标 `invalidated`，归因=`external-interrupt`（**单列计数，不污染预言失效统计**——F5 的分型数据在环内自动化）；新信息入 stateFace「外置变量」行；V 投影重算，残差跳升合法（setpoint 变更≠倒退，闸不吃这个）。
2. **改目标**：旧单账本封段（V 链 A 终态=封段读数），新 Q_N 开链 B；链切换点带证据落盘；terminal 判据只吃链 B。
3. **off**：收编为 setpoint 通道的特例（F4「关闭即结算」）——在途步 invalidated+原因=用户 off，回执含账本快照，重开单可续。
**scanIntent 升级**：现「修改/确认」二态 → 三态（修权重=现「修改」路 / 注入变量=新 / 改目标=新），拒绝文本给可执行出路（教育=违规事件）。
**验收**：打断实验（§F2）——中途改目标，账本零孤儿步、V 链换段自动、无人肉清理。

## G4 更新律——学习进环内

- terminal 时自动执行（不靠人读盘）：输入=本单栈+归因史+measureReads 史+cost 账；输出=G1 候选 entry + sourceModel 命中率更新。
- **源质量标签（S0 先行，最小刀）**：declare 时 predict.source 打类型标签（measured/read/estimate 三值，规则机械判：含命令/文件行号=measured|read，含"惯例/区间/经验"=estimate）；盘档累积「源类 × 回炉」相关性表——**第一份增益信号，纯统计零模型**。72.2% 预言失效里 estimate 类占比即冷启动先验强度。
- 更新方向受棘轮：命中率被实测证伪→标弱不删（两代口径并存可稽，fit-plant v1/v2 惯例）。

## 5. ReAct×spec 融合点（实现语义）

快环=**带证书的 ReAct**（每步落地动作+测量收口，无计划刚性）；慢环=**有生命的 spec**（合同不再是单级文档：草案来自档案、执行中被 setpoint 通道改写、终态蒸馏回档案）；两者之间=G3 通道。传统 spec 之死=写完即僵；传统 ReAct 之死=步步失忆。v0.5 后：spec 会进化，ReAct 有记忆。

## 6. 不变项（红线继承）

三要素闸/双通道/数值邻接硬验/另头审/引文逐字/IOU 到期自红/教育=违规事件/测试即合同/棘轮方向/人持合并按钮。反馈层保持"辅"：**v0.5 一切新闸必须比旧闸便宜**（防仪式膨胀=防北极星 A2 被自家实现违背）。

## 7. 状态 schema v3→v4

新增：`closed[].cost`、`setpointHistory[]`（链段封账）、`externalInterrupts` 计数、predict.source 标签、k-table 引用（草案来源）。迁移：migrateLegacy 只读，旧账零回写；round-trip 严格等值测例逐件补。

## 8. 分期（执行序，各期=测试绿+build+reload+真跑一单）

- **S0 源质量标签**（G4 最小刀，~半天）：declare 打标签+相关性表落盘。先吃 F5 数据红利。
- **S1 setpoint 通道**（G3，纯状态机）：打断/改目标/off 收编+scanIntent 三态。顺带修 F1（autoConfirm 跳窗直通）。
- **S2 R 定价**（G2）：类表+记账+五数+提议判据换口径。
- **S3 K-table + 蒸馏**（G1+G4 全量）：档案结构+terminal 蒸馏+cost_set 召回草案。
- **S4 证伪实验**：F1 学习性/F2 打断/F3 配对——三实验全过，v0.5 称"活 harness"；任一不过，案底文化处理自己。

## 9. 开放问题（执行者与用户讨论，勿默认拍板）

## 10. 诚实边界

- "单步最优=全局最优"的成立前提是模型准确——LLM plant 非线性时变，LQR 给的是**局部化结构纪律**不是最优性定理（搬结构不搬公式的 v0.4 降级版继续有效）。北极星 A2 赌的是"这个结构在工程上够好"，S4 实验就是赌约的结算日。
- 增益档案=统计先验，不是训练；若先验持续被证伪，出路是 v1.0 训练 meta 模型（JIT-Agent-27B 开源可作对照起点），那是另一场战役。
- 三性中"自主优化收敛性"现状依赖人写对 Q——全自主的上限=参考输入的上限，这是设计不是缺陷（A5），但对外叙事勿越过这条线。
