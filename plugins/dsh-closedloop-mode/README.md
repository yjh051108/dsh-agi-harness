# dsh-closedloop-mode（最优律闭环协议插件）

把 agent 的「一次生成再逐步修」开环，换成「预测先行 → 实现 → 盘上实测对账」的闭环：
开工前先声明「做完怎么知道它是对的」（预测 + 来源 + 验证通道），实现后实跑对照——
全吻合=自动闭合；不吻合=预言作废、回滚重推。不存在「调试」状态。

核心门（最小决策单元：条件 + 可学参数 + 证据 + 决策函数 + 不可学约束）：
- 写闸：未声明当前动作时写盘被拒（侦察与测量全程自由）；
- 来源纪律：预测值必须带来源（read/probe/prior），缺来源=拒；
- 判分器棘轮：判分器只能被拧紧，不能被被审者放松；
- 审计硬验：回执引文必须为盘档原文逐字子串（伪造即拒）；
- 真人帧签收：交付反馈只认真人固定词（模型自封=拒）；
- 信誉账本：三层权重（会话/项目/harness）+ Wilson 下界 + 模型指纹绑定；
- 教训台账：跨会话只给类别级通用提醒（案例原文只对同会话）。

环境变量：`DSH_HOME`（盘档根，缺省 ~/.dsh）；`DSH_STAMPER_JS`（可选外部签名脚本）；
`DSH_RECALIBRATE_JS`（可选离线再校准脚本）；`DEEPSEEK_API_KEY`（可选语义裁判凭证，缺省降级机械判定）。

测试：`node --test tests/`（全部自包含，任意机器可跑，不依赖任何真实盘档）。

详见仓库根 README / docs/INSTALL.md。
